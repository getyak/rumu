## 0. 一句话

**一个千年经典的活体年轮库:AI 长出土壤,人类在上面刻下署名的批注,时间让它们入木。**

不是读书 App,不是笔记工具,不是 AI 聊天产品。它更接近一座**可以走进去的、还在生长的碑林**。

- 受众:在 AI 内容洪水里仍然想亲自读的人。对 AI 生成内容高度敏感、反感 slop。中文为主,中英双语内容并存。
- 页面的唯一任务:让人在 5 秒内感到"这本书是活的,而我可以成为它历史的一部分"。
- 免登录可读全站;登录才能落笔与使用 AI。

## 1. 绝对禁则(违反任何一条即整体返工)

1. **全站无计数。** 没有点赞、没有阅读量、没有粉丝数、没有热度排序。任何地方出现数字徽章都是错的。地位只有一种视觉表达:批注"入木"(见 6.2)。
2. **AI 没有声音、没有脸。** AI 生成/整理的内容一律:淡墨灰、无署名、无头像、无气泡、不用第一人称,永远标注「底图 · AI 整理」。AI 的视觉气质是"地质层",不是"对话者"。**绝不出现拟人化的 AI 角色、作者化身、聊天头像。**
3. **不做 feed。** 没有无限滚动的时间线、没有推荐流、没有"猜你喜欢"。首页是书架,不是流。
4. **不像"AI 产品"。** 禁用:渐变、玻璃拟态、霓虹光晕、闪烁的星星✨图标、深紫-蓝渐变、"魔法"隐喻。这个产品的科技含量全部藏在水面下。
5. **人的批注永远署名、带日期。** 人与 AI 的视觉区隔必须一眼可辨,不允许模糊地带。
6. 无弹窗、无引导气泡轰炸、无 emoji 装饰。

## 2. 设计原则(五条)

1. **文本即界面。** 经文本身是最大的 UI 元素,一切功能挂在字句上,不另设容器。
2. **时间是第二坐标轴。** 每个页面都要能感到"纵深"——横轴是内容,纵轴是千年。
3. **留白即立场。** 一屏之内,内容占比宁少勿多。留白不是没设计,是设计本身。
4. **摩擦即身份。** 门槛(抄经、选体)的界面要庄重、仪式化,不要做成阻碍式的验证码体验。摩擦的视觉语言是"研墨",不是"排队"。
5. **一处放胆,处处收敛。** 全站唯一的 signature 是**时间滑杆**(见 5.3),其余一切安静。

## 3. 视觉系统

### 3.1 色 — 「墨字朱批」

用色的文化根据:中国批注传统即"墨字朱批"——正文用墨,批语用朱砂。本产品把这个传统直接编码为语义色:

- `--paper`:暖白纸色 `#F7F4EC`(近玉版宣,不要冷白)
- `--ink`:浓墨 `#1F1D1A`(正文/标题,不用纯黑)
- `--ink-light`:淡墨 `#8A8578`(**AI 底图专用色** + 次要信息)
- `--cinnabar`:朱砂 `#B03A2E`(**人的批注专用**:署名、选体徽章、入木标记、链接激活态。全站唯一强调色,用量克制——一屏之内朱砂出现不超过 5 处)
- `--seal`:印泥深朱 `#7A241B`(朱砂的按压态/深色文字场景)
- `--verdigris`:青绿 `#5E7A6B`(唯一的第二辅助色,仅用于"青芽"状态的新批注,取"青芽入木"之意)

夜读模式(暗色):`--paper` → 深墨蓝黑 `#15161A`,`--ink` → 米白 `#E8E3D6`,朱砂微微提亮为 `#C9564A`。暗色不是反色,是"灯下夜读"的氛围——整体更暗、更静,对比度略降。

### 3.2 字

- **经文/正文(中文)**:宋体系衬线,首选 汇文明朝体,回退 Noto Serif SC。经文字号 20–22px,行高 2.3–2.5,字间距 0.05em。经文允许竖排作为书籍详情页 hero 的装饰性引文(仅装饰,正文阅读一律横排)。
- **UI/功能文字(中文)**:Noto Sans SC,13–15px,行高 1.7。
- **西文与数字**:Spectral(衬线场景)/ Inter(UI 场景)。年份数字用 old-style figures(如字体支持),让日期看起来像刻上去的,不像仪表盘。
- 字重只用两档:400 / 500。禁 600+。
- 层级靠字号、颜色、留白建立,不靠加粗轰炸。

### 3.3 版式与密度

- 内容主栏最大宽度 640px,居中。地层抽屉展开时可扩展至 880px(阅读栏 + 地层栏)。
- 区块间距大:段与段 ≥ 48px,章与章 ≥ 96px。
- 分割线:0.5px 淡墨细线,或干脆用留白代替线。
- 圆角:卡片 8px,徽章 4px。不做大圆角药丸风。

### 3.4 动效

- 全站动效预算:少。时长 240–400ms,ease-out,无弹跳、无回弹。
- 三个被允许的动效:① 时间滑杆拖动时地层的显/隐(淡入淡出 + 轻微纵向位移);② 句子房间展开(地层自上而下依次浮现,间隔 60ms,像剖面被逐层照亮);③ "入木"的一次性仪式动效(批注从青绿缓慢转为朱砂,2s,仅发生一次)。
- 尊重 prefers-reduced-motion。

## 5. 逐页规格

### 5.1 首页 — 千年书架

**Hero 即书架本身,没有营销区。** 打开就是一条横向时间轴,从公元前 600 年到今天,横贯整屏。每本书是一枚**竖立的书脊**,立在它诞生的年份上;书脊的**厚度 = 累积年轮的密度**(注疏、译本、批注越多越厚)。《道德经》立在 -400 附近,是最厚的一枚。轴上稀疏地标注世纪刻度。

- 悬停一本书:浮出极简卡(书名、一句话、"已生长 2400 年 · 137 层年轮"——注意这是描述性文字,不是计数徽章,不带任何互动数字)。
- 页面顶部仅一行:产品名 + 一句话定位 + 「考据」入口 + 登录。不要导航栏堆砌。
- 底部一行小字说明世界观:"越老的书,年轮越厚。"
- 上线初期只有 1–3 本书:书架要在稀疏时依然成立——大量留白 + 时间刻度本身即内容,空不是缺陷,是"等待被种下"的余地。可以在远处年份上放几枚極淡的虚位书脊(淡墨、不可点),示意森林会生长。

### 5.2 书籍详情页 — 一本书的传记

**结构:一条垂直时间线,从诞生走到今天,今天的尽头是这个社区。**

- Hero:书名(大号衬线,可配一列竖排引文作装饰)、成书年代、一句有立场的定位(如:"五千字,两千年读不尽")。无封面图——用文字和留白本身当封面。
- 时间线主体:每个节点是一个 **StoryAtom 卡**:`年份 + 人物 + 一段 120 字以内的故事 + 锚定的原文句(衬线引文)`。示例节点:王弼注(约 240)/ 河上公本 / 敦煌写本 / 马王堆帛书出土(1973,此节点做特殊处理:显示"经文在此改变",给出变字对照)/ 托尔斯泰(1893)/ Waley 译(1934)/ Le Guin(1997)/ The Beatles《The Inner Light》(1968)……
- 每个节点右下角一个安静的入口:「与守树人细究此节 →」(登录后可用;未登录点击则显示登录邀请,措辞见 §7)。
- 时间线的最后一站永远是**今天**:展示最近"入木"的 2–3 条社区年轮(署名 + 朱砂),文案:"这本书仍在被写下。" 这是从"看历史"到"进入历史"的转场。
- 从任意节点可跳入阅读页对应章节。

### 5.3 阅读页 — 经文中轴(核心页面,先做这一页)

**Signature 所在。整个产品最重要的一屏。**

- 布局:一章一屏。居中主栏,经文大字衬线,行高 2.4,四周大量留白。屏内只有:章号(小字,letter-spacing 拉开)、经文、页脚一枚极小的"抄录本章,获得落笔资格"入口。无侧栏、无工具条。
- **时间滑杆(signature)**:页面顶部一根 2px 细轴,从 -300 到 2026,轴上有极小的刻度点(对应该书的关键年份)。拖动圆点:
  - 页面上所有"晚于当前年份"的地层痕迹淡出;
  - 拖过 1973(帛书出土):**经文本身变化**,变化的字以朱砂下划线高亮,悬停显示通行本/帛书本对照;
  - 滑杆右端默认停在"今天"。
  - 交互要"慢而重"——拖动有轻微阻尼感,像在转动某个古老的仪器,不要灵敏得像视频进度条。
- 句中有地层的句子:以**极淡的朱砂底线**标示(不是链接蓝,不是高亮块)。悬停时底线加深。点击 → 句子房间。
- 键盘:← → 翻章;时间滑杆支持方向键微调。

### 5.4 句子房间 — 一句话的全部地层

点击一句后,阅读栏右侧推开一个地层抽屉(桌面端并排;移动端全屏下钻):

- 顶部:这一句原文(衬线,朱砂左边线)。
- 地层按时间**从古至今纵向排列**,每层结构:`来源 · 年份 · 体裁徽章`,正文,(人类批注)署名。
- **AI 底图层**:淡墨色文字、无署名、层右上角固定小字「底图 · AI 整理」。视觉上要像岩层,退在后面。
- **人的年轮层**:墨色正文 + 朱砂署名与日期 + 体裁徽章(注/疑/证/驳,4px 圆角小徽章,朱砂描边)。
- **青芽态**:尚未入木的新批注,青绿色署名 + 「青芽」小标,视觉重量轻于入木层。
- **入木态**:朱砂署名,与王弼、Le Guin 们享受完全相同的排版待遇——这是产品最重要的平等宣言:**今人入木后,与古人同列。**
- 层与层之间可"接续"(回应),接续以细线相连,形成跨年对话的视觉——两条相隔三年的批注连在一起时,日期差要显眼(如"3 年后")。
- 抽屉底部:「在此落笔」(需先抄经解锁)。

### 5.5 落笔流程 — 摩擦的仪式化

四步,每一步一屏,节奏庄重:

1. **抄经**:上半屏显示本章经文(淡墨),下半屏是输入区;用户逐字键入,**键入正确的字从淡墨变为浓墨**——像墨迹在纸上显影。错字轻微震动提示,不弹红色错误框。完成时无烟花、无勋章,只有一行小字:"你已读过。可以落笔了。"
2. **锚定与选体**:选中要批注的字句(朱砂高亮),然后四选一:**注**(我如何解)/ **疑**(我不懂什么)/ **证**(我的生命印证或推翻了它)/ **驳**(我不同意某条年轮——需指定目标层)。每个体配一行 12 字以内的说明。
3. **书写**:极简编辑器,衬线字体,无富文本工具栏(只允许纯文本 + 换行)。
4. **守门人**:提交前,页面下方浮出一条淡墨色的提问(AI,无头像无署名,样式同底图):如"这一段与王弼之注几乎同义——你自己的东西在哪?" 用户可修改后再提交,或坚持提交(守门人只问一次,不阻断;它是镜子,不是墙)。提交后批注以青芽态出现。

### 5.6 守树人 — 每本书唯一的 AI(登录后)

**这不是聊天产品,界面上要主动"去聊天化":**

- 入口低调:书籍详情页与阅读页角落的一行小字「问守树人」。
- 对话界面:无头像、无气泡。用户的问题居右(墨色),守树人的回应是**一条"路径"而非一段答案**:由 2–4 张引用卡组成——每张卡是真实的地层引用(原文句 / 某条注 / 某条署名年轮),卡可点击直达句子房间。引用卡之间允许一两句淡墨色的过渡语(不超过 20 字)。
- 守树人永远不给结论、不安慰、不用感叹号。它的动词只有:"这里有一句""有人在此写过""要过去看看吗"。
- 顶部常驻一行极小的免责小字:"守树人只引路,不作答。"
- **典型入口场景要在设计中体现**:用户带着人生问题来("我该不该离开这段关系"),守树人回以路径。设计一个空状态:"带着一个真实的问题来。"

### 5.7 考据入口 — "这句话真的是他说的吗"

独立的极简页(也是获客落地页):

- 一个输入框:"粘贴一句'古人说'"。
- 结果两种形态:
  - **真**:出处卡(原文 + 章节 + 这句话的年轮密度),一键进入句子房间;
  - **伪**:一张"伪托卡"——"此句不见于《道德经》任何传世本与出土本。最早可溯源至 ____。" 设计要克制而不嘲讽。
- 两种结果都自动生成分享卡(见 5.9)。

### 5.8 我的树 — 个人档案(登录后)

- 每个人一棵抽象的树的可视化:读过的章 = 枝,留下的年轮 = 叶,入木 = 叶转朱砂,被接续 = 枝上连出细线。**手绘感的、生长缓慢的、值得年底截图的**——不要数据仪表盘,不要柱状图。
- 下方:周年回声区("一年前的你在'知止不殆'写下——现在的你还这么读吗?")。
- 这一页是唯一允许出现"回顾/统计感"的地方,但依然无计数徽章——用形态表达量,不用数字。

### 5.9 分享卡片模板

每条年轮/每次并置/每张考据结果可导出为图片卡:

- 竖版 4:5 与方版 1:1 两个模板。
- 结构:原文句(大字衬线)→ 批注正文 → 朱砂署名与日期 → 底部一行小字:产品名 + "此句已生长 N 年"。
- 纸色底 + 墨字 + 朱砂,无二维码大方块(角落极小的域名即可)。卡片必须美到"愿意当壁纸"。

## 6. 组件规范摘要

### 6.1 人 vs AI 的视觉隔离(最高优先级)
| | 人的年轮 | AI 底图 |
|---|---|---|
| 正文色 | 浓墨 | 淡墨 |
| 署名 | 朱砂署名 + 日期 | 无署名,「底图 · AI 整理」角标 |
| 徽章 | 注/疑/证/驳 | 无 |
| 层级 | 前景 | 背景(可整体折叠) |

### 6.2 状态语义
- 青芽(verdigris)= 新批注,待时间与同侪确认
- 入木(cinnabar)= 被采入正式地层,与古人同列
- 入木是全站唯一的"地位",且不可购买、不可加速。

### 6.3 登录墙的形态
未登录用户点击任何需登录的动作时,不弹 modal 轰炸,而是原地展开一行衬线小字:"读是自由的。落笔与问路,需要一个名字。→ 留下名字"

## 7. 文案语气

- 极简、陈述句、不劝、不感叹、零 emoji。
- 系统永远不说"快来""立即""解锁你的"。
- 示例:空状态不写"这里还没有内容哦~",写"此句尚无今人落笔。"
- 按钮动词:落笔 / 抄录 / 接续 / 细究 / 问路。命名全站一致。

## 8. 响应式

- 移动端:句子房间由侧抽屉改为全屏下钻;时间滑杆保留(加大触控热区);书架横轴可横向滑动。
- 键盘可达、焦点可见、reduced-motion 全部尊重。

## 9. 交付顺序

1. **阅读页 + 句子房间**(含时间滑杆——先把 signature 做对)
2. 书籍详情页(传记时间线)
3. 首页书架
4. 落笔流程
5. 考据入口 + 分享卡
6. 守树人 + 我的树

每一步先出一版,停下等确认再继续。第一版以《道德经》第十一章为真实内容(用文档 5.4 中提到的真实地层:王弼、河上公、帛书对照、Le Guin,再虚构 1–2 条署名今人批注作占位,占位批注要写得像真的——具体、有生命细节,禁止 lorem ipsum 式空话)。

深度分析，上面只是建议，我还是希望你帮我设计一套出色的系统，有趣的，对用户来说有新奇感和收藏欲的，探索欲的

充分自由发挥设计，第一眼一定要趣味化，可以有一些动效，交互，游戏感，引入用户眼球
