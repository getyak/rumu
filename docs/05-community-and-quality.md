# 05 · 社区与质量

## 归属感原理（一句话）

归属感不是「社区功能」堆出来的。原理只有一句：**我在这里被看见，我在这里留下的东西不可磨灭，而且我们共同站在某个东西的对面。**

## 五层归属设计

### 第一层：门槛即身份

反直觉但关键：归属感强的社区都有摩擦。进来不该是「注册即入」，而是一个小仪式——你必须先在某棵树上留下第一圈真的年轮（一段真批注，不是打卡），才能看见别人的。**先读，才有说的资格。** 这个摩擦筛掉会稀释社区的人，留下的人因为「付出过」而在乎。这里是一个不能被生成、必须亲自到场的地方。

### 第二层：不可磨灭的痕迹

归属感最深的来源是「我在这里留下的东西，永远在」。一条批注被采入某棵树的正式年轮后，永久署名，和王弼、和 Le Guin 并排——「我成了这本书历史的一部分」。任何 Discord、任何论坛给不了：那边的发言会沉底，这里的年轮会长进树里。

### 第三层：跨年的对话

树的时间性要被用起来：你三年前在「知止不殆」上留的批注，今天有人在下面接了一笔——系统告诉你。**读者和读者隔着时间对话，而不是在时间线上互刷。** 这是「慢」从美学变成机制的地方，也是和一切实时社区的本质区别：这里的对话以年为单位，不以分钟。

### 第四层：我的树在长

每个人有自己的一片林——读过的书、留过的年轮、走过的张力，渲染成一个只属于他的、会生长的视觉结构（DayPage 编译美学的直接复用）。一年后回看自己的林子，那种「我确实在长」的感觉，就是复购的理由。**付费买的不是内容，是这份档案的保存与生长。**

### 第五层：共同的对面

社区凝聚力最强的粘合剂是「我们 vs 什么」。这个社区天然有：**我们是在 AI 洪水里仍然亲自读的人。** 不用喊口号，产品的每一个设计（慢、摩擦、署名、留白）都在无声地说这句话。反 slop 情绪就是这个社区的外墙。

## 留存玩法：让「慢」从美学变成机制

- **一季一书**：不做书库，做节律。整个社区一个季度只读一本书，一周共读一章。所有人的注意力压在同一句话上——不用聊天室就能产生「共同在场感」的唯一办法，也天然制造 FOMO（这一季的年轮，过了就是历史）。
- **周年回声**：你一年前在某句上留的批注，今天被推回给你：「一年前的你在这里写下了这个，现在的你还这么读吗？」——和自己隔年对话，是日记产品里被验证过的最强留存钩子。
- **对读**：系统发现两个人在同一句上留下方向相反的「证」，发起一次一对一、慢节奏的通信式对谈（不是即时聊天，一天一封），对谈沉淀为这句话年轮里的一条「张力」。**分歧不是社区的危险，是社区的内容。**
- **年度实体书**：每年把个人的年轮编译印成一本实体小书——你这一年在千年文本上留下的痕迹。留存钩子、付费点、以及最贵的那种转发（晒实体书）三合一。

## 倒逼优质评论：不筛人，筛「落笔的那一刻」

这是心脏。所有 UGC 社区的宿命是劣币驱良币。解法不能是「审核」（不 scale 且伤感情），必须是**结构性地让烂评论写不出来**。四道闸门，层层递进。

### 第一道：抄经解锁

想在某章落笔？先把这一章逐字抄录一遍（打字即可）。这从抄经传统直接借来——它同时是阅读证明、是仪式、是冷却期、是门槛。愿意为 81 个字花三分钟的人，不会留下「说得好」「顶」这种东西。**摩擦不是体验的敌人，是身份的原料。**

### 第二道：必须锚定，必须选体

没有自由漂浮的评论区——每条年轮必须锚在具体的字句上，且必须选一个「体」：

- **注**：我如何解；
- **疑**：我不懂什么；
- **证**：我的生命里哪件事印证 / 推翻了它；
- **驳**：我不同意某条已有年轮，指名道姓。

这四个体继承注疏传统（注 / 疏 / 笺 / 评点），选体这个动作本身就逼人想清楚「我到底要说哪一种话」。其中「**证**」是差异化武器——历代注家有学问，但只有活着的读者有今天的生命经验，这是这个社区能往千年地层里添的、独一无二的那一层。

### 第三道：苏格拉底守门人

落笔提交前，agent 读一遍，只做一件事——挑战它的「个人性」：

> 「这段和王弼的注几乎同义，你自己的东西在哪？」
> 「你说『很有感触』，是哪件事让你有感触？」

**AI 在这里不写一个字，只负责把泛泛逼成具体。** 这也是对 AI 粘贴内容的天然免疫：generic 的文字过不了这道门，而 generic 恰恰是 AI 生成物的指纹。

### 第四道：没有点赞，只有「入木」

全站不显示任何计数——没有赞、没有热评、没有排序竞赛。唯一的地位只有一种：你的年轮被采入这句话的正式地层，和王弼们排在一起，永久署名。

新批注先以「**青芽**」形态存在，要经过时间 + 被他人引用 / 接续 / 驳，才慢慢「**入木**」。地位无法速成、无法刷量，只能被时间和同侪确认。初期的「采入」由创始人亲自做（你就是第一个园丁）——这不是负担，这正是品味变成产品护城河的方式。

## 两句诚实话

1. 上面每一道门槛，同时都是增长的刹车——抄经会吓跑 95% 的路人，这是故意的。健康指标从第一天起不是 DAU，是「入木率」和「周年回声打开率」。别用错尺子量它然后自我怀疑。
2. 玩法列了这么多，上线时只许带三样：核心阅读页（时间滑杆 + 地层）、抄经解锁、考据 agent 入口。其余全部留在抽屉里。功能是弹药，不是开场白。
