# 00 · 概览

一页读懂入木（Rumu）。

## 一句话

千年经典的活体年轮库：AI 长出主干，人类刻下署名的年轮，时间让它们入木。

## 核心机制（也是名字）

全站唯一的地位叫「入木」。你的批注被时间和同侪确认，采入一句话的正式地层，与王弼、与 Le Guin 并列——「我成了这本书历史的一部分」。名字即激励系统：写得足够深，以至于沉进木头里。

## 一个闭环

AI 长出土壤 → 人往上刻年轮 → 年轮沉淀成个人档案 → 档案凝结成身份，而年轮同时通过两个出口（GEO 引用 + 卡片转发）把新读者拉回来。**流量和归属由同一个东西产生——那圈人的年轮。**

这就是为什么「如何带来流量」和「如何产生归属感」是同一个问题。任何把两者拆开的做法，都会做成「内容站 + 挂了个论坛」的缝合体，那是这类项目的标准死法。

## 三条铁律

1. **免登录看全部**——读是自由的，说是有门槛的。门槛设在落笔，不设在门口。GEO 的前提是机器能爬到全部地层；登录墙 = 在 AI 引用时代自杀。
2. **AI 只有结构，没有声音**——AI 长主干、做向导、挖故事、连图谱，但作者永不开口，AI 永不给结论、永不替你读书。给了 AI 声音，就进入价值坍塌区（人人都能让模型 cosplay 老子）。
3. **慢是机制，不只是美学**——一季一书、跨年对话、抄经解锁、时间滑杆。这个社区的对话以年为单位，不以分钟。

## 健康指标

从第一天起就不是 DAU。是**入木率**和**周年回声打开率**。上面每一道门槛都同时是增长的刹车——抄经会吓跑 95% 的路人，这是故意的。别用错尺子量它。

## 上线只带三样

核心阅读页（时间滑杆 + 地层）、抄经解锁、考据 agent 入口。其余全部留在抽屉里。功能是弹药，不是开场白。

## 第一棵树

《道德经》第十一章。用真实地层（王弼、河上公、帛书对照、Le Guin）做第一版。
