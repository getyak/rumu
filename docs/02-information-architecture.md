# 02 · 信息架构

## 读写分离：看是自由的，说是有门槛的

- **免登录**：任何人（和任何机器）可以看到全部内容——阅读、地层、故事、年轮。这是命脉，不是可选项。GEO 要求机器能爬到全部地层；归属感产品的正确门槛结构永远是「门槛设在落笔，不设在门口」。
- **登录换能力**：登录只用于解锁 AI 能力、深度对话、以及落笔（发表年轮）。身份换能力，读写分离。

## 首页：时间书架（Lindy 书架），不是封面墙

首页不是网格封面墙，也不是 feed。它是**一条跨越三千年的横轴**，每本书立在它诞生的年份上，书脊的厚度 = 累积的年轮密度。一眼看去，「时间」这个产品母题就说完了。

排序原理：**越老、越多人读过的书越有价值。** 时间本身是筛选系统（Lindy 效应）——活得越久的文本，越值得往上刻。

## 书籍单元：一本书 = 一个独立的、沿时间线生长的传记页

产品的基本单位不是「文章」，是「那本书本身」。每本书有一个独立网页，是它的「主干」，从诞生走到今天：

```
诞生（成书）
  → 历代注疏（王弼、河上公……）
  → 出土 / 校勘事件（马王堆帛书、郭店竹简……）
  → 翻译与再创作（Le Guin、Mitchell、Beatles……）
  → 今天这个社区的年轮
```

一条垂直时间线走到底，每一站是一个 **StoryAtom**（见 [03 产品形态](./03-product-form.md#故事集)），每一站可以召唤 AI 深聊。

## 优雅的入库逻辑

一本新书第一次进入系统时，有一个优雅的输入处理管线：把原始材料编译为一个「优雅的书籍详情」——一个独立网页，沿时间线把后世名人与这本书的关联不断串起来，一直到今天，组成一个可以逐段与 AI 交互的页面。（编译管线复用 raw→wiki 的方法论，schema 换成 StoryAtom。）

## 检索

产品同时提供两套检索：

1. **最前沿的 AI 产品形态**：自然语言追问、考据、跨文本连线（见 [04](./04-ai-and-agents.md)）。
2. **传统的书籍筛选系统**：按时间轴、按年轮密度、按注疏谱系浏览。

## 层级总览

```
时间书架（首页）
└── 书籍传记页（主干 / 时间线）
    └── 章 / 节（一屏一章）
        └── 句（点开 = 一个「房间」）
            └── 地层（注 / 译 / 帛书对照 / StoryAtom / 人的年轮）
```
