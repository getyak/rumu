# 04 · AI 与 Agent

## 铁律：AI 只有结构，没有声音

移植自 Solo Compass 的原则——**AI-as-filter, never AI-decides。** 在这个产品里具体化为：AI 是图书馆里那个知道每本书在哪的管理员，不是替你读书的人。

- **AI 长主干（冷启动）**：每本经典的初始结构、注疏的数字化整理、跨文本的链接建议——全在后台，不署名为「内容」，署名为「底图」。
- **AI 做向导，永远指向人的年轮**：用户读到「上善若水」，AI 不讲解这句话（价值坍塌区），而是说：「这一句，河上公和王弼读法相反，而三个月前用户 X 在这里留下过一段和你处境很像的批注——要去看看吗？」
- **AI 做苏格拉底，不做百科**：只提问、只并置、只指出张力，不给结论。这不是产品限制，是产品立场——这个地方存在的意义就是练「自己搞明白」，AI 替你嚼碎的那一刻，产品的魂就死了。

## 被否决的方向（重要）

以下构想全部**不做**，因为它们给了 AI 声音：

- ❌ 每本书裂变出一群 agent；
- ❌ 作者本人是个会说话的 agent（「老子 agent 和你聊天」= 同人文，零稀缺，正是价值坍塌区）；
- ❌ agent new 出任务 agent、用「道德经 skill」直接解决爱情问题给答案；
- ❌ 把 `soul.md` / `user.md` / `skills` / agent 拓扑暴露到产品表面（那是建造者的大脑漏进产品——用户只看见水，不关心水管）。

三个致命理由：**(1)** 违反唯一铁律；**(2)**「和历史人物聊天」是被 Character.ai 反复验证过的坟场（新奇即弃，无留存）；**(3)** 在一个慢资产里嵌了个快消玩具，还让玩具站在门口。

**作者永不开口，恰恰是这个产品的尊严：作者只留下了文本，剩下的两千年是读者的。**

## 五个接入点（按价值排序）

### 1. 考据 agent —— 最锋利的获客钩子

「这句话老子真的说过吗？」中文互联网伪托名言泛滥（「鲁迅：我没说过」是全民梗）。做一个极简入口：粘贴任何「老子说 / 庄子说 / 孔子说」，agent 溯源——

- 真的：给你原文、章节、历代怎么读它；
- 假的：告诉你它实际最早出现在哪。

每一次查证，结果页就是那棵树的一个房间。这是工具型流量往深度产品的漏斗，查证结果本身就是可转发的卡片。

### 2. 苏格拉底 agent —— 落笔前的守门人

见 [05 社区与质量](./05-community-and-quality.md#第三道苏格拉底守门人)。它是质量系统的核心。

### 3. 编译 agent —— DayPage 机制平移

用户的高亮、抄录、批注，夜间编译成他那棵「个人的树」的生长——今天长了哪一枝，哪条年轮被人接续了。打开 app 看自己的树长了没有，就是留存的日常动线。

### 4. 跨树连线 agent —— AI 提议，人批准

AI 发现你在「知止不殆」上的批注和《沉思录》卷四某段有共振，推给你：「要不要走过去看看？」你确认，这条连线才成立，并署你的名。**AI-as-filter, never AI-decides。** 每条被人确认的连线又反过来加厚图谱。

### 5. 把树做成 MCP server —— 让 agent 成为分发渠道

最超前的一步：把整棵树暴露成结构化接口，让任何 AI 助手都能调用查询（「王弼和河上公在第十一章的分歧是什么」）。别人做内容站等 Google 收录，入木直接成为 AI 时代的基础设施被机器引用。**GEO 的终极形态不是被引用，是被调用。**

## 守树人（一书一 agent）

用户的「带人生问题进来」直觉，正确的收敛形态：**每本书只有一个 agent——守树人 / 引路人。** 它接住你的问题，然后只做一件事：领你走进地层。

你问「我该不该放手」，它不回答，它说：

> 「第九章『功遂身退』——王弼这样读，而 2024 年有一个署名『阿禾』的人在这里留下过一段和你几乎一样的处境——要过去看看吗？」

每一步都是引用，每一步都可点进真的年轮。**AI 是门童，不是神谕。**

「skills」的正确形态叫**路径**：人策的走读路线（「止损与放手」= 一串章节 + 精选年轮），AI 只负责领路。路径是内容，skill 是水管——把水管藏起来。

### 前台约束

守树人：无头像、无气泡；回答永远是「引用卡组成的路径」而非文段；顶部常驻一行「守树人只引路，不作答」。`soul.md`、`skills` 那套留在后端，前台一个字都不露。
